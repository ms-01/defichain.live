# DeFiChain.live

[![CI](https://github.com/ms-01/defichain.live/actions/workflows/ci.yml/badge.svg)](https://github.com/ms-01/defichain.live/actions/workflows/ci.yml)

**Website:** https://defichain.live

## About

DeFiChain.live is a community-maintained website providing information,
resources, and access to the DeFiChain ecosystem.

This repository is based on the original DeFiChain website project.
Its purpose is to preserve existing resources and support the
long-term continuity of the DeFiChain ecosystem.

## Development & Contributing

Community contributions are welcome.

Please open an issue to report problems or suggest improvements.
Pull requests are welcome.

See [CONTRIBUTING.md](CONTRIBUTING.md) for additional guidance.

### Requirements

- Node.js
- pnpm

Use the Node.js version specified in `.nvmrc`, where applicable.

### Installation

Run `pnpm install` to install dependencies.

### Local development

Run `pnpm run dev` and open http://localhost:3000.

## Technology

The website is built with Next.js and deployed through Netlify.
